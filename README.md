# Priyanka Lamba — Technical Program Management Portfolio

A responsive portfolio website showcasing four technical program management case studies.

## View the site
After enabling GitHub Pages, the site will be available at:

**https://priyankalamba026.github.io/technical-program-management-portfolio/**

## Publish to GitHub Pages

1. Download and extract the website ZIP.
2. Open your repository: https://github.com/priyankalamba026/technical-program-management-portfolio
3. Upload `index.html`, `styles.css`, and the `case-studies` folder to the **root** of the repository (preserve folder structure). You may also upload this README.
4. Commit your changes.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select your default branch (`main`), folder **/(root)**, then **Save**.
8. Wait for GitHub Pages to publish and open the URL above.

## Update case studies
Replace the relevant PDF in `case-studies/` with a revised version, keeping the filename unchanged.

## Notes before making public
The website uses the final portfolio PDFs available in this conversation. Review every PDF carefully before publishing: remove any internal names, IDs, nonpublic architecture, confidential dates, or proprietary details. The site does not include source code or original internal screenshots. Numerical claims should be independently validated for public disclosure.

## Technology
Plain HTML and CSS; no build tools, dependencies, tracking scripts, or backend required. The page uses Google Fonts when available and system-font fallbacks otherwise.
